# 卡券结算报表与规则设置静态部署版

这是一个无构建步骤、无第三方依赖的静态演示站点，包含：

- 实际结算报表
- 卡券规则设置

## 本地预览

在本目录运行：

```bash
python3 -m http.server 8081
```

浏览器访问 `http://127.0.0.1:8081/`。

## 部署

将本目录内的全部文件原样上传到静态 Web 服务器的站点根目录即可。默认入口是 `index.html`。

支持 Nginx、Apache、对象存储静态网站、GitHub Pages 等静态托管方式。站点使用 Hash 路由，不需要配置服务器重写规则。

## 注意

- 必须通过 HTTP/HTTPS 访问，不建议直接双击 `index.html`，因为导航配置通过 `fetch` 加载。
- 当前使用 Mock 数据，操作不会写入真实系统。
- 生产化需要把 `mock/data.js` 与页面内演示操作替换为真实接口。
